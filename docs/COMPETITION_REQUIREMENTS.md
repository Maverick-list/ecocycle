## 2. Judging Criteria & Strategic Scoring Breakdown

The development of ECOCYCLE is engineered systematically against the published judging scoring rubric.

### 2.1. Preliminary Round (*Babak Penyisihan*)

```
┌────────────────────────────────────────────────────────┐
│             PRELIMINARY ROUND SCORING                  │
├────────────────────────────┬───────────┬───────────────┤
│ Criteria                   │ Weight    │ Target Score  │
├────────────────────────────┼───────────┼───────────────┤
│ Environmental Theme        │ 30%       │ 29% / 30%     │
│ User Experience (UX)       │ 25%       │ 24% / 25%     │
│ Visual Design & Aesthetics │ 20%       │ 19% / 20%     │
│ Testing & Performance      │ 15%       │ 15% / 15%     │
│ Website Functionality      │ 10%       │ 10% / 10%     │
├────────────────────────────┼───────────┼───────────────┤
│ TOTAL                      │ 100%      │ 97% / 100%    │
└────────────────────────────┴───────────┴───────────────┘
```

1. **Environmental Theme Relevance (30%)**:
   - *Strategy:* Avoid superficial environmental cosmetics. Provide concrete environmental computational tools (waste weight to CO₂ offset conversion formulas, methane reduction metrics, certified recycling categories based on Indonesian KLHK standards).
2. **User Experience / UX (25%)**:
   - *Strategy:* Streamlined navigation hierarchy, clear visual cues, zero dead ends, accessible color contrast ratios (WCAG 2.1 AA compliant), intuitive form validation with helpful error messages, and frictionless interactive widgets.
3. **Visual Design & Aesthetics (20%)**:
   - *Strategy:* Bespoke modern aesthetic ("Eco-Brutalism meets Clean Glassmorphic Botanica"): purposeful typography, polished micro-interactions, subtle glass backdrop blurs, harmonious color harmony (Forest Emerald, Bio-Mint, Warm Stone, Earth Gold).
4. **Testing & Performance (15%)**:
   - *Strategy:* Lightning-fast static bundling, optimized WebP/SVG vector imagery, sub-1.5s First Contentful Paint (FCP), 0 Cumulative Layout Shift (CLS), target 98–100 Lighthouse benchmark across Performance, Accessibility, Best Practices, and SEO.
5. **Website Functionality (10%)**:
   - *Strategy:* All interactive elements actually work (filtering articles, tab switching, waste deposit calculation, simulated transaction generation, interactive pledge counter, responsive navigation drawer).

## 3. Data Integrity & Demonstration Ethics

To protect academic honesty and adhere to product principles:
- **No Fabricated Impact Claims**: The platform does not claim real-world metric achievements or fake institutional endorsements.
- **Explicit Watermarking**: All demonstration datasets (mock waste bank locations, simulated transaction ledgers, example exchange rates) will carry an explicit informational tag:  
  `[Mode Simulasi / Competition Demonstration Data]`
- **Real Computational Formulas**: Mathematical conversions between waste volume and carbon offsets are grounded in verified environmental literature (e.g., ~1.5 kg CO₂ reduction per 1 kg recycled PET plastic; ~1.1 kg CO₂ per 1 kg recycled paper/cardboard).
